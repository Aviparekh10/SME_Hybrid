# Threat Model (v1)

## In-scope
- Invalid tx signatures
- Invalid invoice state transitions
- Simple spam (rate limits + fee sorting)
- Invalid blocks / PoW mismatch
- Basic peer misbehavior (drop/ignore)

## Out-of-scope for v1 (v2)
- Eclipse attacks, advanced Sybil defenses
- Economic incentives, robust fee market
- KYC/AML enforcement
- Stablecoin custody + audits
- Arbitration game theory & bribery resistance
